Privacy

What CommitCraft stores

CommitCraft is a GitHub publishing tool. It stores the minimum data needed to keep you signed in and to publish the files you select. There is no analytics tracking, no advertising and no selling of data.

Your GitHub account

When you sign in, GitHub returns an access token and your public profile (login, display name, avatar URL). The token is encrypted with AES-GCM before it is written to Cloudflare KV, and it is only decrypted inside the Worker when a GitHub request is made. It is never sent to the browser.

Your session is identified by a random, HttpOnly cookie. JavaScript on the page cannot read it. The session expires automatically after 14 days, or immediately when you sign out.

Uploaded files

Files are read in your browser. When you confirm a publishing plan, their contents are sent to the Worker over HTTPS so it can create Git blobs and commits. File contents are deleted from server storage as each commit succeeds, and the whole job expires within 7 days at most.

Files excluded by the smart ignore rules are never uploaded. Files that look like secrets (.env, private keys, credential files) are blocked by both the interface and the API.

Publishing history

Each job stores the repository, branch, status, timings, file counts and the commit SHAs that were created. You can delete this at any time from Settings → Security. Deleting history never deletes commits from GitHub.

Local browser storage

The browser keeps your theme preference, your last selected repository and branch, and — while you are between screens — the folder you uploaded (in IndexedDB). No tokens are ever stored in localStorage or sessionStorage by CommitCraft.

Third parties

CommitCraft talks to GitHub's REST API on your behalf, and loads the Inter and JetBrains Mono fonts from Google Fonts. No other third-party requests are made by the application.
